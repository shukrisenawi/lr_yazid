# Semakan borang — 23 November 2026

## Pemeriksaan automatik akhir

- Backend: 357 lulus, 28 dilangkau (385 keseluruhan), 2,677 assertions.
- Frontend: 102 ujian lulus dalam 24 fail.
- Build frontend, PHP Pint, PHPStan dan TypeScript: lulus.
- `npm run check`: lulus selepas output build dikecualikan daripada formatter.

## Skop dan kaedah

Semakan kod borang dalam `resources/js/pages` dan `resources/js/components`,
ujian penghantaran melalui Chrome DevTools pada `http://localhost:8000`,
serta suite ujian automatik. Borang berulang menggunakan komponen yang sama
dikumpulkan mengikut aliran; ini bukan dakwaan setiap kombinasi input telah diuji.

Akaun pelanggan/VIP QA baharu digunakan berasingan daripada sesi admin.
Data simulasi ditandakan `QA Forms` atau `QA-FORMS`. Tiada pembayaran sebenar,
pemindahan wang, penghantaran barang atau panggilan ToyyibPay dibuat.

## Masalah yang dibaiki

1. **Redirect selepas validation salah:** `Referrer-Policy: no-referrer` menyebabkan
   Inertia kehilangan halaman borang asal selepas navigasi SPA. Tukar kepada
   `same-origin`; URL tidak dibocorkan kepada laman luar. Ujian regresi dan pelayar
   mengesahkan kegagalan alamat kekal pada borang.
2. **Setup 2FA terpadam semasa pengguna masih mengisi borang:** polling notifikasi
   melakukan partial refresh halaman security setiap 30 saat. Cleanup Fortify
   menganggap setup ditinggalkan. Partial refresh dan cubaan kod yang gagal kini
   mengekalkan setup. Full-page revisit masih membersihkan setup yang ditinggalkan.
3. **Cache QR lama selepas tutup modal:** data QR/setup dibersihkan setiap kali
   modal ditutup, bukan hanya selepas 2FA berjaya diaktifkan.
4. **Pengasingan ujian:** SSR dimatikan dalam base test supaya suite tidak menghubungi
   dev server dan bercanggah dengan HTTP fakes. Formatter mengecualikan output build.

## Had / perkara yang tidak disahkan sebagai transaksi sebenar

- **Start payment / reconcile dengan provider:** kutipan dimatikan dan tiada
  credential provider sah. Tidak dihantar kepada ToyyibPay; liputan automatik
  menggunakan respons HTTP mock bukan bukti penerimaan sandbox sebenar.
- **E-mel masuk inbox:** mailer tempatan menggunakan log. Penghasilan pautan dan
  penggunaannya diuji, bukan penghantaran SMTP/inbox.
- **Semua kombinasi input, semua pilihan keputusan dan semua peringkat fulfillment**
  tidak diulang dalam pelayar. Suite automatik meliputi banyak kes negatif,
  pemilikan rekod, harga, stok, workflow dan idempotency.
- Upload editor diuji menghasilkan HTTP 200; semakan ini tidak mengesahkan senario
  menekan Save ketika upload editor masih berjalan. Pengguna perlu menunggu upload.
- Logo/favicon website tidak diganti dengan imej QA; submit tetapan sedia ada diuji.
- `DeleteUser.vue` tidak dipasang pada halaman profil semasa. Ia bukan borang yang
  boleh dibuka melalui UI; tiada akaun pengguna sebenar dipadam.
- Konsol dev mempunyai amaran Vue lazy hydration / extraneous non-props attributes;
  ia tidak dianggap telah dibaiki oleh semakan ini.
